# Half-Life_hackclub_Operation-Vinn
The second project of halflife

In this project I will try to solve the problem with my cat his kibble. He has his kibble in the morning and the evening. Often we forget if het got his food. So in this project I am gonna come up with an idea to make it clear if he has gotten his morning food or evening food! (His name is Vinn, thats why its operation-Vinn)
